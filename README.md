# Rachael Marketplace

A mobile-friendly Kenya marketplace starter for Rachael Ventures.

## Included
- Property, cars, businesses, products and services categories
- Search and filtering
- Listing form
- Local browser storage for listings
- WhatsApp contact button
- Responsive mobile design

## Important
This version is a working front-end MVP. Listings are stored in the visitor's browser, not a shared online database. To make listings visible to everyone and accept paid/featured listings, connect the app to a hosted database/authentication and payment provider, then deploy it on a hosting service.
